## Overview

An end-to-end sales data analytics project focused on **data cleaning, transformation, analysis, and visualisation**.

The project uses **Python, SQL, Excel, and Power BI** to transform sales data into meaningful business insights and an interactive dashboard.

## Tools Used

- Python & Jupyter Notebook
- SQL
- Excel
- Power BI
- GitHub

## Workflow

**Raw Data → Data Cleaning → Python Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

## Repository Structure

- `data/` – Sales datasets
- `Notebook/` – Python analysis
- `Power BI/` – Dashboard files
- `ScreenShorts/` – Project screenshots

## Skills Demonstrated

Data Cleaning • ETL • Python • SQL • Power BI • Data Visualisation • KPI Analysis • Business Insights
